# IMDB-
🎬 IMDB Movie Performance Dashboard – Overview

This dashboard analyzes movie performance using key financial and rating metrics. It highlights total revenue, profit, budget, and average IMDb ratings to provide a clear view of overall performance.

The report includes revenue trends over time, budget vs profit comparison, rating distribution, and top-performing movies by revenue. It helps identify which movies and franchises performed best financially and critically.

Built using Power BI and DAX to demonstrate data modeling, KPI creation, and business-focused visualization.
